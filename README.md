# Which modelling choices are supported when marine survey data are limited? An evidence map of 95 studies and a benchmark on structured subsamples of a trawl survey

Code, data and results for:

> Afrifa-Yamoah, E., Siqueira, A. C., Awuah-Mensah, Y. K., Fouedjio, F. and Mueller, U. (2026). Which modelling choices are supported when marine survey data are limited? An evidence map of 95 studies and a benchmark on structured subsamples of a trawl survey. Manuscript submitted. Preprint: https://doi.org/10.32942/X2JM49

The repository holds (i) the evidence map coding sheet and the script that draws the map as a matrix, (ii) the benchmark scaffold that draws structured subsamples from the NWFSC West Coast Groundfish Bottom Trawl Survey (via `surveyjoin`), fits five species distribution models to each subsample and evaluates them against the held out survey, (iii) the analysis and figure scripts, (iv) the result tables and figures from the 10 replicates per cell run, and (v) the Supporting Information. The repository is archived on Zenodo: https://doi.org/10.5281/zenodo.23102980 (release v1.0.0). To cite it, use that DOI together with `CITATION.cff`.

## The committed benchmark run

The committed results are from one run of the full design with `BENCH_REPS=10` (run of 25 September 2026, R 4.3.3, package versions in `results/sessioninfo_smoke_test.txt`). The design is 5 sample sizes x 2 coverages x 2 targets x 10 replicates for each of 3 species (Dover sole, lingcod, canary rockfish), with 5 models per replicate, so 600 replicate runs and 3000 model rows are expected. `results_all.rds` holds 2965 rows (593 replicate runs). The 7 missing replicate runs are all canary rockfish (the rare species, prevalence 0.084) at n = 30 under dispersed coverage (1 conditional, 6 marginal). Replicates in that cell needed up to 40 redraws to meet the minimum of five presences and five absences, and the scaffold gives up after 50 attempts; those 7 replicates were not recorded, which is why Table S15a reports 53 rather than 60 runs for every model in that cell. The committed scaffold records such cases as rows with `model` NA and an `error` message, so a rerun will show them explicitly. Nothing else is missing: no error rows, and all cells other than that one have the full 60 runs.

Every table in `results/analysis_out/` was checked against `results_all.rds` before release (row counts, failure rates, cell means, the species table and Table 4 reproduce exactly from the committed RDS file), and the supplementary tables listed above were checked against the CSV files.

## Reproducing the benchmark

Requirements: R >= 4.3 with `surveyjoin` (>= 0.0.5), `sdmTMB` (>= 1.1.0), `blockCV` (>= 4.0.0), `ranger`, `mgcv`, `sf`, `DBI`, `rnaturalearth`, `rnaturalearthdata`, `dplyr`, `tidyr`, `readr`, `stringr`, `ggplot2`, `patchwork`, `future.apply`, `lme4`, `emmeans`, and optionally `ragg`. `surveyjoin` needs its data cache (`surveyjoin::cache_data()` then `load_sql_data()`); the scaffold prints the haul counts it loads so the cache can be checked. The committed run loaded 12414 hauls from NWFSC.Combo for 2003 to 2023 after dropping 258 hauls without bottom temperature.

```sh
# 1. smoke test: two cells (n = 500 dispersed conditional; n = 30 clustered marginal), one replicate each,
#    prints a projected run time and writes results/smoke_test.rds (not archived)
Rscript R/benchmark_scaffold.R

# 2. full design: 5 sample sizes x 2 coverages x 2 targets x 5 models x 3 species x BENCH_REPS replicates
BENCH_RUN_FULL=TRUE BENCH_WORKERS=2 BENCH_REPS=10 Rscript R/benchmark_scaffold.R     # about 2 h 20 min on 2 cores

# 3. tables, figures and maps
Rscript R/analysis.R
Rscript R/figures_results.R
Rscript R/figures_sampling_designs.R
Rscript R/figure_evidence_map.R
```

Replicate seeds are generated per design row by `future.apply` (`future.seed = TRUE`), so a rerun with the same `BENCH_REPS`, the same package versions and the same survey cache reproduces `results/results_all.rds` independently of `BENCH_WORKERS`. A run with a different `BENCH_REPS` changes the design table and is not guaranteed to share replicates with the committed run. The design figures use their own seed (20260925) and do not touch the benchmark.

## Evidence map coding sheet

`data/evidence_map_coding_sheet.csv` holds one row per coded study with the contrast codes used by `figure_evidence_map.R` (spatial against non spatial within a family; algorithm family with spatial treatment held constant; both crossed; coverage against record count; validation design), the reported sample size range, marine status, metric family and the finding each study supports. It currently codes 25 sources prefilled from the manuscript, among them the 12 studies selected for detailed quantitative extraction (Table S6), and it does not code all 95 studies of the corpus. The counts of main text Table 1 are derived from the citation commands of the manuscript as described in Appendix S1.3, not from this sheet; `figure_evidence_map.R` prints its own counts beside those of Table 1 so that the two can be reconciled.

## Conventions

Sample size is a discrete design factor and no figure joins the sample sizes with a line. The five model colours (Okabe and Ito palette) mean the same five models in every figure; the design maps use grey, black and a reddish purple for pool, training subsample and evaluation set, and fold identity uses viridis. Figures carry no titles; captions live in the manuscript. Every numeric value in the manuscript is taken from `results/analysis_out/`.
